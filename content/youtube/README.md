# محتوى يوتيوب — حزم إنتاج Edutainment

هذا المجلد مخصص لحزم إنتاج الفيديوهات: سكريبت كامل + مرئيات + تحقق معلومات + بيانات نشر.
منفصل عن أدلة `docs/ar/` الخاصة بحزمة التركيز، ولا يغيّر أيًا منها.

| الملف | الوصف |

| [`final-video.md`](final-video.md) | **الفيديو الجاهز:** الفصول بالتوقيتات الحقيقية + الوصف + المصغّرة + طريقة إعادة البناء. |

## طريقة الاستخدام

1. اقرأ `edutainment-template.md` وحدّد: المفارقة + الرقم القاتل + الوعد.
2. املأ الفصول الخمسة، ثم اكتب الخطاف **أخيرًا** بعد أن تعرف أفضل رقم في الفيديو.
3. اقرأ السكريبت بصوت عالٍ: أي جملة تتعثر فيها = جملة تُقصّ.
4. املأ جدول التحقق قبل التصوير، لا بعده.
5. لا تنشر حتى تُنجز قائمة التحقق في نهاية الحزمة.

## سياسة الدقة (إلزامية)

- كل رقم في السكريبت له **مصدر رسمي + تاريخ** في جدول التحقق.
- التنبؤات تُكتب بصيغة «محتمل/مشروط/دُرِس»، لا بصيغة «مقرر».
- ما لا يمكن التحقق منه يُحذف — حتى لو كان أقوى جملة في الفيديو.

> الأرقام في حزمة الكاش محدّثة حتى **أكتوبر 2026**. أعد التحقق منها قبل أي إعادة نشر بعد 3–6 أشهر.
